## 3. Diretrizes para Atualização do Catálogo

Ao criar ou atualizar qualquer especificação:
1. Atribua o próximo número incremental sequencial (`SPEC-001`, `SPEC-002`, ...).
2. Atualize o status na tabela conforme o avanço do ciclo de vida (`[DRAFT]`, `[REVIEW]`, `[APPROVED]`, `[IN_PROGRESS]`, `[DONE]`, `[DEPRECATED]`).
3. Mantenha os links atualizados para o arquivo correspondente em `docs/sdd/specs/`.
